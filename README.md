# 照片歸檔工具 (Photo Archiver) v8.14

以瀏覽器執行的照片整理工具，用於大量照片的檢視、分類、刪除與重新命名。
不需安裝軟體，照片不會上傳，所有處理都在本機進行。整理結果會產生一個 `.bat` 執行檔與一份檔名參照表。

線上版本：[https://progress01.github.io/photocheck/](https://progress01.github.io/photocheck/)

---

## 功能概要

1. **篩選**：將不需要的照片標記為刪除，執行後移至 `_TRASH` 資料夾。
2. **分類**：依主分類將照片移入對應資料夾。
3. **命名**：依「主分類_子標籤_流水號」規則重新命名，例如 `DSC_1234.jpg` → `活動_長官致詞_001.jpg`。
4. **自訂檔名**：可個別保留原檔名或手動修改。
5. **參照表**：產生一份 HTML 對照表，可點擊檔名複製，供報告使用。

## 使用方式

### 1. 開啟工具

- 直接開啟線上網址，或下載 `index.html` 後以 Chrome / Edge 開啟。
- 第一次開啟會出現新手導引，可選擇跳過。

### 2. 載入照片

點擊右上角「📂 選擇資料夾」，選取存放照片的資料夾。

- 只會讀取所選資料夾**最外層**的照片，子資料夾（例如 `_TRASH` 或已整理過的分類資料夾）內的照片不會讀取。
- 支援格式：`.jpg` `.jpeg` `.png` `.gif` `.webp` `.bmp`。
- iPhone 的 `.HEIC` 格式無法在 Windows 瀏覽器中預覽，請先轉為 `.JPG`。

### 3. 分類與檢視

| 操作 | 按鍵 |
|---|---|
| 選擇主分類 | `1` ~ `4`（可自訂） |
| 選擇 / 取消子標籤 | `A` `S` `D`（可自訂，可複選） |
| 標記 / 取消刪除 | `Delete` |
| 下一張 | `Enter` 或 `→` |
| 上一張 | `←` |
| 旋轉預覽 | `R`（僅影響預覽，不修改原始檔案） |
| 切換自訂檔名 | `F2` |

- **原地改名**：不選擇主分類時，照片保留在原資料夾，只修改檔名。
- **自訂檔名**：關閉「自動流水號」後，輸入框會帶入原始檔名，可直接修改。
- **重複檔名偵測**：檔名與其他照片重複時，會顯示警告。
- **紀錄清單**：點擊「📝 紀錄」可查看已命名的照片，點擊項目可跳回該張修改；修改後可用「⏩ 回到最新進度」返回。
- 按鍵依鍵盤實體位置判斷，中文輸入法開啟時也可使用。

### 4. 輸出與執行

1. **「📄 下載檔案參照表 (.html)」**
   - 顯示整理後的照片與新檔名，點擊檔名可複製。
   - 參照表依整理後的路徑讀取圖片，需先執行 `.bat` 才會顯示圖片。

2. **「⚡ 下載整理執行檔 (.bat)」**
   - 將 `開始整理.bat` 放入照片資料夾後執行。
   - 執行檔會建立資料夾、移動並重新命名照片。
   - 目標位置已有同名檔案時會略過該筆，不會覆蓋。
   - 執行結束後會顯示成功、略過、失敗的數量；略過與失敗的項目會在畫面中標示。

## 其他設定

- **設定分類**：點擊「⚙️ 設定分類」可新增、修改、刪除主分類與子標籤，以及設定按鍵。
  - 按「儲存設定」後才會生效；未儲存就關閉時會詢問是否儲存。
  - 修改名稱時，已套用的照片會同步更新。
  - 刪除已有照片使用的項目時，會先顯示受影響的數量。
- **組合鍵模式**：可設定兩個字元的按鍵（例如 `QW`、`12`）。開啟後單鍵操作會有約 0.3 秒的等待時間。
- **鎖定分類**：開啟後，下一張未分類的照片會自動沿用上一張的分類與標籤，適合連續同類的照片。
- **流水號起始值**：分批處理時可修改起始值（例如 `101`），避免與前一批檔名重複。
- **特殊字元過濾**：檔名中的 `\ / : * ? " < > |` 會自動移除或替換。

## 常見問題

### 執行 .bat 時出現 Windows 藍色警告視窗

這是 Windows 對網路下載腳本的預設防護。點擊「其他資訊」→「仍要執行」即可。

### 整理後照片不見了

照片已移至新建立的分類資料夾或 `_TRASH` 資料夾。本工具只執行移動與重新命名，不會永久刪除檔案。

### 參照表的圖片無法顯示

參照表依整理後的路徑讀取圖片，請先執行 `.bat`。

### 執行 .bat 後顯示有「略過」或「失敗」

- **略過**：目標位置已有同名檔案，原檔案仍保留在原處。
- **失敗**：找不到原檔案（可能已被移動）或檔案正在使用中。

可往上捲動執行視窗，查看標示為 `[略過]` 或 `[失敗]` 的檔案。

### 更新後畫面仍是舊版本

請按 `Ctrl + F5` 重新整理，並確認左上角的版本號。若使用的是下載到本機的 `index.html`，需重新下載。

- 修正：組合鍵模式下，按分類鍵後立即按 `Enter`，分類未被套用。
- 修正：在自訂檔名輸入框中以注音選字時，按 `Enter` 確認文字會切換到下一張。
- 調整：長按 `Enter`、`Delete` 或分類、標籤鍵時不會連續觸發。
- 調整：`Ctrl`、`Alt` 組合鍵（如 `Ctrl+C`）不再被視為分類或標籤按鍵。
- 調整：數字鍵盤可用於分類按鍵。
- 新增：取消標籤、取消刪除時顯示提示。

**分類設定**
- 修正：修改分類或標籤名稱後，已套用的照片未同步更新（標籤會從檔名消失、照片不會出現在參照表）。
- 調整：設定改為按「儲存設定」後才生效；未儲存就關閉時會詢問是否儲存。
- 新增：刪除已有照片使用的分類或標籤前，顯示受影響的照片數量。
- 新增：儲存時檢查名稱空白、名稱重複，以及未開啟組合鍵模式時使用多字元按鍵的情況。

**載入與執行檔**
- 調整：只讀取所選資料夾最外層的照片，不讀取子資料夾。
- 新增：已有分類進度時，重新選擇資料夾前會先確認。
- 修正：`.bat` 以系統管理員身分執行時，工作目錄錯誤。
- 修正：檔名含 `%` 時，`.bat` 無法正確處理。
- 修正：移至 `_TRASH` 時會覆蓋同名檔案。
- 修正：原地改名時，若新檔名與原檔名只有大小寫不同（如 `.JPG` → `.jpg`），會被判定為已存在而略過。
- 新增：`.bat` 執行結束後顯示成功、略過、失敗的數量。
